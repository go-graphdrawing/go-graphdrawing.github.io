Why the name

Graph drawing is the discipline's own name — the GD conference, and Di Battista, Eades, Tamassia and Tollis. Naming the org after the field means the code inherits the literature's vocabulary: a layering pass is a layering pass, a network simplex is a network simplex, and a reader who knows the papers can follow the source.

It is deliberately not called layout. In this fleet that word already means widget layout, and a repository called go-layout would be read as user-interface code by everyone who saw it.

Status: reserved, not started

The name and the shape are settled. The code waits for a consumer that needs it — and the measurement says that consumer is not TeX.

What the reference costs

pgf's graphdrawing, driven from LuaTeX, is 167 files and 37 163 lines of Lua — of which some 2 000 are TeX↔Lua glue a Go port would not need.

What it would buy TeX

Across 10 025 real beamer talks, 5 use it. Building 37 000 lines for five documents is the worst effort-to-effect trade in that project.

What will trigger it

Diagrams. Isometric and node-link diagrams where automatic placement is the feature. Graph placement is not TeX-specific and should not be born inside a TeX engine.

A Lua interpreter is not the shortcut it looks like, either: the reference is driven through LuaTeX's own API, so running it unchanged would mean emulating LuaTeX rather than merely having a Lua VM.
